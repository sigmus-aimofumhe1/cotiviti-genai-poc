## Executive Summary

This repository contains the complete assessment submission for the **Temp Intern - GenAI Sci** position at Cotiviti. 

The project addresses **Topic 2: Clinical Decision Making and Pattern Recognition in Health Care**, focusing on classification, anomaly detection, and agentic decision support within Healthcare Treatment, Payment, and Operations (TPO).

It introduces a **Two-Stage "Classify-and-Explain" Framework**:
1. **Stage 1 (Predictive Screening):** A high-speed machine learning model (Random Forest Classifier) evaluates claims data to calculate real-time anomaly risk scores before payment disbursement.
2. **Stage 2 (Agentic Decision Support):** An Explainable AI (XAI) engine analyzes model feature contributions and generates structured, human-interpretable audit summaries for medical reviewers.
